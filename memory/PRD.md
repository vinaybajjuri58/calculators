# FinCalc - Personal Finance Calculator Web App

## Original Problem Statement
Build a lightweight, responsive personal finance calculator web app with 20 calculators including Mortgage, EMI, Credit Card Payoff, Compound Interest, Investment Growth, Retirement, FIRE, ROI/CAGR, Savings Goal, Debt Snowball, Debt Avalanche, Inflation Impact, Net Worth, Life Insurance, Expense Ratio Impact, Opportunity Cost, Position Size, Risk/Reward, Break-even, and Amortization. Features include searchable currency selector, no login required, elderly-friendly design with cream/beige and teal color scheme.

## Architecture
- **Frontend-Only**: Pure React application with all calculations done client-side
- **No Backend Required**: Maximizes performance and simplicity
- **Tech Stack**: React 18, CSS3 with CSS Variables, Space Mono + DM Sans fonts

## User Personas
1. **Retirees/Elderly** - Need simple, clear interface for retirement and investment planning
2. **First-time Homebuyers** - Mortgage and loan calculators
3. **Investors** - Compound interest, FIRE, ROI/CAGR calculators
4. **Debt Managers** - Snowball/Avalanche debt payoff strategies
5. **Traders** - Position size, risk/reward calculators

## Core Requirements (Static)
- [x] 20 finance calculators
- [x] Searchable currency selector (30+ currencies)
- [x] Responsive design (mobile, tablet, desktop)
- [x] Elderly-friendly UI (large fonts, high contrast)
